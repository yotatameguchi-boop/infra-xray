# Security model

## 保護対象

planのvariables、outputs、password、user_data、任意のtags、その他許可リスト外の値をUIへ送らないこと。sensitive属性は再帰マスクします。unknown属性は推測せず診断不能として扱います。許可リストが空のリソースを丸ごと転送するフォールバックはありません。

機密属性を含むJSONのパースエラーは元の文字列を出さずに通知します。標準ライブラリ例外も汎用エラーに変換します。アクセスログは無効です。CLIが出力する起動URLにはアクセストークンが含まれますが、入力ファイルの値は含みません。

## ローカルHTTP

- 127.0.0.1のみにバインド。
- APIは起動ごとに生成するトークンのAuthorizationヘッダーが必須。
- URL fragmentでUIにトークンを渡し、読み取り後にURLから削除。現在のタブのsessionStorageへ保存。
- Hostを正確に検証し、DNS rebindingを拒否。
- cross-site fetchを拒否。CORS許可ヘッダーなし。
- CSP、no-store、nosniff、no-referrerを設定。
- 静的ファイルはパッケージ内のstatic配下に限定。パストラバーサル拒否。
- 外部CDN、解析テレメトリー、外部フォントなし。依存JSはビルド時に同梱。

## 境界と限界

悪意あるローカル管理者、ブラウザー拡張、同じ端末の侵害に対する保護は提供しません。起動URLやトークンを他者へ渡さないでください。

Terraformアドレス・許可リスト属性そのものに秘密を埋め込んだ場合や、Terraform側でsensitive指定がされていない許可リスト属性を機密情報として利用した場合、その機密性を一般的に検出することはできません。インフラ識別子は表示対象です。

SG-001は各リソース内の全IPv4 SSH許可の変化です。複数の独立リソース間で既に同じ許可があるかは統合評価しません。公開RDSもルーティングやセキュリティグループ次第で実際の到達性は異なります。警告なしは安全宣言ではありません。
